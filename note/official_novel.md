# 📖 小說自動產生器 使用手冊

> 適用版本：V0.12.9.0 之後
> 對應網頁：`web/novel_generator.html`

## 一、整體流程

小說創作分成四個粒度，**每一層都可以由作者介入修改，AI 根據該層產生下一層**：

```
粗綱 (整個故事梗概) → 章 (章節大綱) → 節 (每節細綱) → 內文 (實際文字)
```

- **正向**：作者寫粗綱 → AI 生章 → 作者調整 → AI 生節 → 作者調整 → AI 生內文
- **反向**：作者丟一本既有小說 → AI 分析出節→章→粗綱（📋 文檔轉條列 / 📄 文檔轉粗綱）
- **局部優化**：任何一層寫好的文字，都可以框選局部段落，用熱鍵請 AI 擴寫／精簡／優化對白／視覺化改寫（見「八、✨ 選取文字 AI 加工」）
- **全域檢視與編輯**：不管內容散在哪一層，都能一次搜尋所有文字（見「九、🔎 全面搜尋」），或切換到全螢幕逐節並排編輯（見「十、🖥️ 全畫面編輯」）

## 二、頂部工具列

| 按鈕 | 功能 |
|---|---|
| ☁️ 讀取雲端小說 | 從 Supabase 讀取已儲存的小說清單（最新 1000 筆） |
| 💾 儲存雲端小說 | 儲存到雲端（含密碼）與本機 .json |
| 📂 讀取小說 | 從本機讀取 .json 檔 |
| 📤 匯出小說🔽 | 展開下拉選單，可選擇兩種匯出格式（見下） |
| 🧰 額外功能🔽 | 展開下拉選單，內含以下五個功能按鈕 |
| 🚀 全自動 | 依粗綱自動生成多本小說（含章→節→內文） |

### 📤 匯出小說🔽 的兩種格式

| 選項 | 內容 |
|---|---|
| 📤 匯出小說 章標題+內文 | 只匯出「章標題」與「內文」，等同一般小說格式，適合直接拿去投稿或閱讀 |
| 📤 匯出小說 粗綱+章+節+內文+作者備註 | 匯出完整資料：粗綱、各章標題與描述、各節標題、內文，並在文末附上「作者備註」 |

### 🧰 額外功能🔽 選單內容

| 按鈕 | 功能 |
|---|---|
| 📝 作者備註 | 撰寫作者備註，**不會提供給 AI**，但會隨小說一起儲存／讀取 |
| 📚 比對多本小說 | 並排比對四本雲端小說的粗綱／章節／節／內文（只能比對，無法在此儲存） |
| 🎯 評論小說 | 依使用者的提示詞來評論目前小說或外部文檔 |
| 📝 多文改寫 | 依使用者的提示詞來改寫大量外部文檔，例如翻譯、切換觀點、增減字數…等 |
| 🌐 網路搜尋並依序改寫 | 依工作項目自動上網搜尋資料，並依序讓 AI 產生對應的內容 |

## 三、登場角色欄

### 演員 vs 劇本角色名

- **角色卡（下拉選單）** = 演員：從角色庫中挑選具備完整人設的角色卡
- **角色名稱（左邊文字輸入欄）** = 劇本中的角色名

範例：角色卡「惠茹」演出劇本中的「寶蓮」，AI 收到的 prompt 就會是：

```
女主角姓名：寶蓮
（其他個性、外貌、口吻皆來自「惠茹」的角色卡）
```

這樣可以用同一位「演員」演不同劇本，或讓多本小說共用角色但劇中名稱不同。

### 相關操作

- **🔄**：從雲端重新下載角色卡清單
- **+**：新增一位角色
- **🗑️**：移除該角色 slot

## 五、故事粗綱

- 文字輸入區：撰寫整個故事的走向、結局、關鍵轉折
- **可自行編輯**：以常用的粗綱(梗概)格式寫作或條列式重點格式皆可。
- **📋 文檔轉條列**：讀入本機故事檔，AI 依起承轉合輸出「條列式粗綱」，每個關鍵事件含原走向＋兩條替代戲劇化走向
- **📄 文檔轉粗綱**：讀入本機故事檔，AI 依起承轉合濃縮成簡短粗綱

## 六、故事大綱（章／節）
- 分成"章"與"節"(大綱)兩大部分，可分開編輯。
- 簡單來說，當你寫完粗綱後，可以先按"🤖 章描述"，產生所有章標題與章描述。然後再由你親手修改"章"的內容。
- 確認"章"的內容滿意後，再按"🤖 AI 撰寫所有大綱"，產生所有節的大綱。再親手修改"節"的內容。

| 按鈕 | 功能 |
|---|---|
| 🔒（欄位標題列右側） | 一次上鎖／解鎖**所有章與所有小節**，再次點擊可切換回原狀態 |
| 🤖 章描述 | 根據粗綱生成各章的標題與描述 |
| 🤖 AI 撰寫所有大綱 | 為所有未鎖定的章生成節大綱 |
| 每章標題列的 🔒 / 🔓 | 鎖定／解鎖**該章**，會**連動一併鎖定／解鎖該章底下所有小節** |
| 每小節的 🔒 / 🔓 | 只鎖定／解鎖該小節，AI 不會覆蓋已鎖定的小節 |
| ⠿（章標題列左側把手） | 按住拖曳可調整**整章**的排列順序，用法與拖曳小節相同 |
| 拖曳小節列 | 可在同一章內拖曳調整小節順序 |
| + | 新增章／節 |
| 🗑️ | 刪除章／節 |

**鎖定原則**：作者調整過、已滿意的章／節請按 🔒 鎖定，之後執行「AI 撰寫所有大綱」不會被覆寫。

## 七、內文編輯器

- 確認"節"的內容之後，可由AI生成內文。
- 選中左側任一節（點擊）即會載入該節的內文
- **🤖 AI 本節內文**：只為當前節生成內文
- **🤖 AI 全節內文**：為所有未鎖定的節生成內文
- 內文欄位鎖定（🔒）後 AI 不會覆蓋

## 八、✨ 選取文字 AI 加工（擴寫／精簡／對白／視覺化改寫）

針對「粗綱」、「章描述」、「小節大綱」、「內文」四個輸入框中的**任一段選取文字**，可直接用熱鍵請 AI 就地優化，不需要整段重寫。

### 操作方式

1. 在四個輸入框的其中一個，用滑鼠反白選取一段文字（**必須先選取**，否則會提示「請先選取文字」）。
2. 按下對應熱鍵，會跳出「選取文字加工」彈窗：
   - 上方顯示**原始選取文字**（唯讀）
   - 中間可填寫**補充指示**（選填，例如「擴寫時強調緊張感」）
   - **目標字數**：預設依熱鍵種類自動抓比例，可自行修改
   - 可各別選擇**寫作風格一/二/三、寫作範本、模型參數**（此彈窗的下拉選單獨立於左側全域設定，四種加工模式**各自記住**上次的選擇，並隨小說一起儲存）
3. 按「重新生成」讓 AI 依上下文加工這段文字，結果會顯示在下方預覽區。
4. 檢視結果後，選擇：
   - **附加在選取之後**：把加工結果插入在原選取文字後面
   - **取代選取**：把原選取文字直接替換成加工結果
   - **重新生成**：不滿意可以再跑一次
   - **取消**：放棄本次加工

**回寫標記**：「附加在選取之後」／「取代選取」寫回文字前後，會自動包上分隔標記方便辨識新舊文字的交界：
- 附加：`---從此處附加---` … `---附加結束---`
- 取代：`---從此處取代---` … `---取代結束---`

標記本身前後都會換行、自成一行，確認滿意後可自行刪除；也可以用「九、🔎 全面搜尋」搜尋 `---` 並用「替換所有關鍵字」一次批次清除。

### 四組熱鍵

| 熱鍵 | 功能 | 預設目標字數 | 說明 |
|---|---|---|---|
| Alt + P | ✨ 擴寫／優化 | 選取字數 × 2 | 依前後文補上更多動作、環境互動與細節，讓段落更飽滿 |
| Alt + S | ✂️ 精簡 | 選取字數 × 0.5 | 保留關鍵資訊與轉折，刪除贅字與冗長鋪陳 |
| Alt + T | 💬 對白優化 | 選取字數 × 1 | 依「登場角色」設定，讓對白更符合各角色的說話口吻，去除說教式、解說劇情式的呆板台詞 |
| Alt + A | 🎬 視覺化改寫 | 選取字數 × 1 | 把內心戲、抽象感受改寫成看得到的動作、表情、與環境互動 |

### AI 會參考的上下文（依所在輸入框自動組合）

| 輸入框 | AI 參考範圍 |
|---|---|
| 粗綱 | 整段故事粗綱 |
| 章描述 | 故事粗綱 ＋ 上一章與下一章的標題／描述 |
| 小節大綱 | 該章章描述 ＋ 上一節與下一節的大綱標題 |
| 內文 | 該小節大綱 ＋ 該小節的完整內文（標記出選取的段落位置） |

**注意**：只有滑鼠焦點停留在上述四個輸入框、且有反白選取文字時，這組熱鍵才會生效，不會影響其他輸入欄位或瀏覽器原生快捷鍵。

## 九、🔎 全面搜尋（Ctrl+Shift+F）

模仿常見 IDE（程式碼編輯器）的全域搜尋，跨「粗綱、章標題、章描述、小節大綱、內文、作者備註」六大項目一次搜尋，不用自己一欄一欄找。

### 開啟與介面

- 按 **Ctrl+Shift+F** 開啟浮動搜尋面板，預設在畫面左側，寬度約 1/4 畫面、高度約 90% 畫面；標題列（🔎 全面搜尋）可用滑鼠拖曳移動整個面板位置。
- 面板由上到下：
  1. **搜尋列**：輸入關鍵字，按 Enter 或點 🔍 執行搜尋；❌ 按鈕隱藏面板（資料不會清除，下次再按 Ctrl+Shift+F 可繼續使用）。
  2. **替換列**：輸入要替換成的文字，點「替換所有關鍵字」會先跳出**無法復原**的警告確認視窗，確認後才會把六大項目中所有符合的關鍵字**一次全部替換**。
  3. **狀態列**：顯示「共找到 N 個結果」；若某個項目命中已達上限，會多顯示「繼續搜尋」按鈕。
  4. **結果清單**：依六大項目分組，每組標題右側顯示該項目的命中數量；命中結果以條列顯示「關鍵字前後各 10 字」的預覽片段（過長會以 `…` 省略），並標示所在位置（例如「第3章 第2節」）。

### 使用方式

- **點擊任一筆結果**：自動跳到對應的編輯欄位（粗綱／章描述／小節大綱／內文／作者備註），並反白選取該關鍵字所在位置；若該欄位在搜尋完成後又被編輯過導致位置失效，會提示「內容已變動，請重新搜尋」，不會亂反白到錯誤位置。
- **20 筆搜尋上限**：為避免小說內容龐大時搜尋卡頓，每個項目預設最多只列出 20 筆命中；若某項目命中超過 20 筆，該項目數量後面會加註 `+`，並在狀態列顯示「繼續搜尋」按鈕，點擊後會針對尚未搜尋完的項目取回全部結果。
- **替換所有關鍵字**：務必先確認搜尋結果無誤再執行，此操作**沒有復原機制**（不能用 Ctrl+Z 還原）。

## 十、🖥️ 全畫面編輯

提供一個安靜、無其他介面干擾的編輯環境，把所有小節攤平成「一節一橫行」並排顯示，方便連續瀏覽與微調整本小說。

### 開啟方式

「🖋️ 內文編輯器」工具列的「🤖 AI全節內文」左邊，點擊「🖥️ 全畫面編輯」即可開啟。

### 介面說明

- 頂部：`📝 全畫面編輯` 標題 ＋ 搜尋列（🔍／▲／▼／輸入框，按 Enter 或點方向鈕在雙欄搜尋結果間跳轉，用法與 LOG／評論小說彈窗的搜尋列相同）＋「↕️ 自動調整高度」按鈕 ＋ ❌ 關閉。
- 主體：每個小節一橫行，由左至右：
  - **章編號**：僅一字寬，以繁體中文直式顯示（例如「第十五章」）。
  - **小節描述**：佔畫面約 1/3 寬，內容與主介面「小節大綱」欄位同步。
  - **內文**：佔剩餘寬度，內容與主介面「內文」欄位同步。
- 橫行與橫行之間有**可拖曳的分隔線**，按住上下拖曳可調整該行高度。
- **開窗時自動貼合高度**：每一行會依「小節描述／內文實際渲染後所需的高度」自動撐開，讓文字一開窗就完整顯示，不需要逐一手動拉高；之後若編輯過內容導致文字變長，可點「↕️ 自動調整高度」重新貼合一次（手動拖曳過的高度只有在點這顆按鈕時才會被重新計算覆蓋）。

### 資料同步

全畫面編輯欄位與主介面的「小節大綱」「內文」是**同一份資料**，只是換了個顯示位置：在全畫面編輯中修改會即時寫回，關閉彈窗時主介面（含章節樹的完成狀態 ✓）會整批重新整理顯示最新內容。

## 十一、全自動生成多本小說（🚀）

用同一份粗綱 + 同一批角色，一次自動產生多本結構相似但內容有變化的小說。

| 參數 | 說明 |
|---|---|
| 產生數量 | 一次生成幾本 |
| 生成階段 | 章描述 / 節大綱 / 內文 三階段可獨立勾選 |
| 雲端儲存密碼 | 填入才會儲存到 Supabase，留空則只本機下載 |
| 各階段字數 | 每章描述字數、每節描述字數、每節內文字數 |

檔名格式：`小說名稱-001`、`小說名稱-002`⋯⋯若雲端已有同名小說，會自動從最大序號 +1 開始。

## 十三、比對多本小說（📚）

並排四欄，可分別選擇四本雲端小說進行內容對照，支援：
- 比對粗綱／章描述／節描述／內文／全部
- 顯示生成時使用的`AI大模型參數`。
- 全欄同步搜尋文字
- 一鍵刪除雲端小說

## 十四、🎯評論小說 (這個功能很猛)

兩個功能 `🎯評審目前小說`、`📂評審外部文檔`（📂 評審外部文檔可**一次選取多個檔案**，會依序逐一評審，每個檔案完成後**自動匯出一份 .md**）。

### 選擇評論的立場

| 選項 | 立場 |
|---|---|
| A | 出版社老闆（極度嚴厲，預設） |
| B | 出版社編輯（嚴格但提供實質建議） |
| C | 中文系老師（挖掘優點並補強缺點） |
| D | 愛心家教（發掘特點與可行方向） |
| E | 空白架構（自行填寫） |
| F | 只說優點的誠實讀者 |
| G | 只說缺點的沒耐性讀者 |
| H | 依序執行以上 A~G 所有立場評論 |

- 每個立場都有預設的提示詞，亦可自行修改。`✏️使用者要求（送給 AI 的指令，可自行改寫以加強特定段落的批評）`，各立場的修改內容會分別記住。
- 選擇 **H** 時，除了依序跑完 A~G 七種立場評論，完成後還會**額外送給 AI 一次「最終評審意見」整理**：把七位評審的意見合併，依重要性（越多人提到的越重要）排序，每條意見分別列出正面評論／反面評論／修改建議，最後把 A~G 的原始評論 + 最終評審意見合併輸出成**一份** .md 檔（不會拆成多份）。
- 產出 `🖋️AI 編輯的評審建議`，可自行匯出，這部分不會儲存在小說專案之中，若有需要請自行複製貼入`📝 作者備註`

## 十五、📝多文改寫

依照提示詞依序改寫外部文檔，例如：翻譯、切換視角、潤飾、調整風格、修改語氣等，可**一次選取多個檔案**，依勾選順序逐一改寫並自動匯出。

- 有預設的提示詞，亦可自行修改。`✏️ 使用者指令（送給 AI 的提示詞，例如：翻譯成英文、改寫成小紅書貼文、改寫成兒童讀物…）`
- **指令範本下拉選單**：內建兩組現成範本可直接套用（套用後仍可自行修改）：
  - 小說視角轉換的機械式改寫工具（只做人稱／視角轉換，不動劇情與對白）
  - 日文歌詞翻譯成羅馬拼音＋繁體中文（逐行輸出日文／羅馬拼音／中文翻譯三行）
- 產出 `🖋️ AI 改寫內容（每完成一個檔案會自動匯出）`，自動匯出結果文檔，這部分不會儲存在小說專案之中。

## 十六、🌐網路搜尋並依序改寫

依「工作項目」清單，逐一自動上網搜尋資料，再交由 AI 依指令產生內容，適合需要參考真實資料的創作（例如融入歷史事件、時事背景等）。

- 使用者指令中可用 `{topic}` 佔位符，會自動替換成每個工作項目的主題。
- **指令範本下拉選單**：內建兩組現成範本可直接套用：
  - 混合真實歷史與合理想像的感人短篇（以搜尋到的史實為骨架，空隙處合理想像）
  - 將搜尋回傳資料再次排除不相關內容並以條列式顯示（用於先篩選整理龐雜的搜尋結果）
- 工作項目區採 JSON 格式，允許 `#` 或 `//` 註解、允許省略外層 `[ ]`，每個項目至少需含 `topic` 與 `keyword`，可選填 `specific_urls`。
- 支援 DuckDuckGo 免費搜尋 與 Tavily API 搜尋（Tavily 需自行輸入 API Key）。
- 產出會依序追加在 `🖋️ AI 改寫內容` 區塊，可複製後另行儲存，不會自動存入小說專案。

## 十七、常見問題

### Q：AI 回應「JSON 格式錯誤」怎麼辦？
系統內建 `json_repair` 自動修復機制，多半會自動解決。若失敗會在 LOG 顯示原始回應，可手動貼回讓 AI 重試。

### Q：模型跑很久沒回應？
後端有心跳機制（每 5-30 秒），只要 CMD 視窗還在跑數字倒數就是正常的。逾時上限預設 300 秒無新 LOG 才會判定失敗。

### Q：想重新命名／刪除已存到雲端的小說？
從「📚 比對多本小說」的下拉選單挑選該本，右側 🗑️ 可刪除。目前雲端小說標題無法直接改名，需另存新本後刪除舊本。

### Q：AI 生成的內容會反覆重複同一段？
可調高「模型參數」的 `temperature`（例如 0.9→1.1）或 `repeat_penalty`（1.1→1.3）。

### Q：選取文字加工（Alt+P/S/T/A）沒有反應？
請確認滑鼠游標的焦點確實停留在「粗綱」「章描述」「小節大綱」「內文」四個框之一，且已反白選取一段文字；若焦點在其他輸入框（例如小說名稱）則熱鍵不會生效。

## 十八、資料儲存位置

- **雲端**：Supabase `novel_entries` 表（含 `edit_data` 完整狀態、`novel_full_text` 全文、`password`）
- **本機**：儲存時同時下載一份 `<小說名稱>.json`

作者備註儲存在 `edit_data.authorNotes`，不會傳給 AI。
「選取文字 AI 加工」四種模式各自的補充指示、目標字數、風格／範本／模型參數，儲存在 `edit_data.refineParams`，隨小說一起儲存與讀取。

## 十九、小技巧

1. **善用鎖定**：先讓 AI 生完整本，挑喜歡的章／節按 🔒，再讓 AI 重跑其他部分，可以逐步逼近理想版本；章的 🔒 會連動鎖住底下所有小節，適合整章都滿意時一次鎖定。
2. **多模型比較**：切換不同模型跑同一段粗綱，可以看出各家模型的敘事偏好。
3. **文字檔轉粗綱**：想把既有作品改編？先用「📄 文檔轉粗綱」反推，再改寫粗綱後正向生成。
4. **寫作範本**：貼上你喜歡的作家（或自己）的一段文字當作範本，AI 會模仿口吻與節奏。
5. **局部微調用熱鍵**：不需要整節重寫時，框選有問題的那幾句，用 Alt+P/S/T/A 直接請 AI 就地優化，比重新生成整節更快、更精準。
6. **章節排序**：想調整章節出場順序時，直接拖曳章標題列左側的 ⠿ 把手，不需要手動搬移內容。
7. **快速定位全書任何一句話**：忘記某句台詞或設定寫在哪一章時，別再逐章翻找，直接 Ctrl+Shift+F 打開全面搜尋，點結果即可跳過去。
8. **通篇改名／改稱謂**：角色名稱或稱謂要全書統一更動時，用「🔎 全面搜尋」的「替換所有關鍵字」一次處理（記得先確認搜尋結果無誤，此操作無法復原）。
9. **通讀校對用全畫面編輯**：要一次快速掃過整本小說的每一節內文抓錯字、抓語病時，開「🖥️ 全畫面編輯」逐行往下捲動閱讀，比一節一節點擊切換更有效率。
