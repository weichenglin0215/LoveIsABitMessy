## 2. 三軸定義

### 2.1 軸向規格

| 內部代碼 | 給受測者看（口語） | 兩極 | 心理學底層 |
|---|---|---|---|
| **依附邊界** (Attachment-Boundary) | **黏度** | Fuse（融合焦慮）↔ Free（獨立迴避） | Bartholomew 四類依附整併、邊界融合度 |
| **表達通道** (Channel) | **愛之語** | Ver（言語）↔ Act（行動） | Chapman 五種愛之語化簡為主軸 |
| **浪漫框架** (Frame) | **浪漫度** | Rom（浪漫理想）↔ Pra（務實條件） | 愛情依附理論 + Sternberg 三角理論 |

### 2.2 軸的口語使用

- 結果頁、題目說明、進度提示一律使用 **「黏度 / 愛之語 / 浪漫度」**
- 後台、原始碼、AI 卡內部使用 `Fuse-Ver-Rom` 三字母代碼
- 受測者**不必看到**英文代碼，但分享卡可選擇顯示三字母（給懂的人看）

## 3. 性象限（性標示）

### 3.1 二維結構（四象限）

```
            情感依附高（要愛才能性）
                    │
   深情多元型        │       深情專一型
   (浪漫但開放)      │       (合一專一)
   ────────────────┼────────────────  開放度
                    │
   自由探索型        │       冷靜遊戲型
   (開放且分離)      │       (性愛分離)
                    │
            情感依附低（性可以獨立）
```

### 3.2 四象限命名（給受測者看）

| 象限 | 中文名 | 一句話 |
|---|---|---|
| 高依附 × 專一 | **深情專一型** | 「沒有愛，我給不出身體」 |
| 高依附 × 開放 | **深情多元型** | 「我能愛很多人，但都是真心」 |
| 低依附 × 專一 | **探索人性型** | 「性是性，愛是愛，但我只玩一個」 |
| 低依附 × 開放 | **自由遊戲型** | 「性不需要承諾，愛也不需要獨佔」 |

### 3.3 性題設計

- **共 10 題**，分為兩軸各 5 題（情感依附 5 題、開放度 5 題）
- 開始前顯示提醒：「下一段包含性議題，可選擇整段跳過或單題跳過」
- 每題可獨立選擇「**跳過這題**」

### 3.4 跳過規則（B-2 + B-3）

```
若回答題數 ≥ 6：
    依答題題目計算兩軸平均 → 分到四象限之一 → 顯示性標示卡
若跳過題數 ≥ 5：
    不顯示性標示卡，改顯示：
    「您跳過了較多性議題，本次不進行性象限分析」
```

### 3.5 性標示的呈現位置（C 確認）

- **在結果頁最後一聯**（位於三聯之後）
- 性標示的卡片旁邊有**眼睛圖示** 👁
  - 預設「**眼睛開啟**」 → 顯示性標示文字與類型
  - 點擊「**眼睛關閉**」 → 隱藏該卡內容（適合對外分享截圖時）

### 4.1 總題數

| 段落 | 題數 | 結構 |
|---|---:|---|
| 曖昧期 | 15 | 3 軸 × 5 題（隨機洗牌，雙題庫隨機取用） |
| 熱戀期 | 15 | 3 軸 × 5 題（隨機洗牌，雙題庫隨機取用） |
| 失戀期 | 15 | 3 軸 × 5 題（隨機洗牌，雙題庫隨機取用） |
| 性象限（選填） | 10 | 2 軸 × 5 題（隨機洗牌，可單題跳過） |
| **總計** | **55** | |

### 4.2 排列順序（隨機抽題 + 雙題庫隨機取用）

#### 4.2.1 階段內題目順序：隨機

每階段 15 題（3 軸 × 5 題）**不再固定交錯**，而是在進入該階段時即時隨機洗牌：

```
範例邏輯：
  1. 取出該階段全部 15 題（3 軸 × 5 題）
  2. 對 15 題執行 Fisher-Yates 洗牌
  3. 依洗牌後順序呈現給受測者

結果：
  - 受測者 A 第一次測：題序可能是 C7 → A3 → B12 → A8 → ...
  - 受測者 A 第二次測：題序可能是 B5 → A2 → C9 → B11 → ...
  - 同一個 ID 的題目，每次出現的位置不同 → 重複測試不無聊
```

性象限段落（10 題）同樣採隨機洗牌。

#### 4.2.2 題庫設計：雙版本隨機取用

題庫**同時維護兩份**：

| 題庫 | 文件位置 | 風格定位 |
|---|---|---|
| `LPAS_QUESTIONS_PART1` | `web/js/lpas_questions_v2.js` | **正式版**：略為書面、含蓄、適合稍年長受測者 |
| `LPAS_QUESTIONS_PART2` | `web/js/lpas_questions_v2.js` | **生活版**：高度口語、閨蜜口吻、適合年輕受測者 |

**兩份題庫共用同一套 id 與軸向定義**：

```javascript
// 範例：同一個 Q01，兩個題庫提供不同寫法
LPAS_QUESTIONS_PART1: [
  { id: "Q01", period: 1, axis: "attachment", direction: 1,
    text: "我重視愛情中的親密感與時時刻刻的連結。" }
]

LPAS_QUESTIONS_PART2: [
  { id: "Q01", period: 1, axis: "attachment", direction: 1,
    text: "妳是不是那種喜歡跟對方黏在一起、隨時想知道他在幹嘛的人？" }
]
```

#### 4.2.3 取題邏輯（前端）

```javascript
function pickQuestion(id) {
    const pool = [
        LPAS_QUESTIONS_PART1.find(q => q.id === id),
        LPAS_QUESTIONS_PART2.find(q => q.id === id)
    ];
    return pool[Math.floor(Math.random() * pool.length)];
}
```

→ 每個題目 id 在每次填答時，**從 PART1 / PART2 隨機抽一份呈現**
→ 同一受測者重複測試時，連同一題的「文字」都會變化

#### 4.2.4 軸內正反向題分配

每軸 5 題中：**正向題 3 題、反向題 2 題**（或視題目品質微調至 4+1 / 2+3）
兩份題庫的 direction 標記必須一致（即 PART1 的 Q01 是正向，PART2 的 Q01 也是正向）。

### 4.3 題目寫作風格

#### PART1（正式版）

- 每題最多 25 字，建議 16-20 字
- 可分句，每句最長 14 字
- 用詞較中性、無情感詞綴
- 避免具體例子
- 範例：「我希望伴侶能時常主動聯絡我。」

#### PART2（生活版）

延續 v1 已驗證的口語化、閨蜜口吻原則（參考既有 `LPAS_QUESTIONS_PART2`）：
- 每題最多 25 字，盡量縮短在 16-20 字
- 可分句，每句最長 14 字
- 多用語氣詞：「對吧」「對嗎」「對不對」「是不是」「那種」「啦」
- 句尾常用問號（像閨蜜在問）
- 避免具體例子，用模糊描述
- 必要時加入「第三者」因素（多在黏度與浪漫度軸的反向題）
- 範例：「妳是不是那種希望對方隨時都在訊息裡的人？」

#### 兩版的對照原則

- **id 對應同一個測量目標**：例如 Q01 在兩版都測「主動親密渴望」
- **direction 必須一致**：避免兩版反向不同造成計分混亂
- **psychometric 等價**：兩版題目應引出相近的回答分布（同一個受測者讀兩版應該答得差不多）
- 撰寫時建議**先寫 PART2（生活版），再「翻譯」回 PART1（正式版）**，確保意涵一致

### 5.4 AI 卡使用方式（J 確認）

作者撰寫小說大綱時，**在角色名稱後註明當前期間**：

```
範例小說大綱：
  女主角【林沛雯（公主-女王-浪子）】，目前在【熱戀期】
  → 小說程式判定 → 抓取「女王」型的 AI 卡 + 三階段樣貌中的「熱戀期」段
  → 注入 prompt

  情節推進到分手後 →
  作者把【林沛雯】改為【失戀期】
  → 小說程式自動切換 → 抓取「浪子」型的 AI 卡 + 失戀期段
```

→ 小說程式只需在生成時根據「期間標記」切換 AI 卡內容，**不需理解軸向強度**。

## 9. 計分邏輯

### 9.1 每階段每軸計分

```javascript
for each stage in [曖昧期, 熱戀期, 失戀期]:
    for each axis in [黏度, 愛之語, 浪漫度]:
        score = 0
        count = 0
        for each question in 該階段該軸的 5 題:
            raw = answer (1-7)
            if question.direction == -1:
                raw = 8 - raw  // 反向題翻轉
            score += raw
            count += 1
        avg = score / count  // 1.0 - 7.0

        if avg >= 4.0:
            label = 該軸正向標籤（Fuse / Ver / Rom）
        else:
            label = 該軸負向標籤（Free / Act / Pra）

    階段三軸標籤組合 → 查表得 8 型之一
```

### 9.2 性象限計分

```javascript
answered = 已回答的性題數量
if answered >= 6:
    情感依附軸 avg = 已回答的依附題平均
    開放度軸 avg = 已回答的開放題平均
    根據兩軸落入四象限之一
    → 標籤：深情專一型 / 深情多元型 / 冷靜遊戲型 / 自由探索型
else:
    顯示「跳過太多題，無法分析」
```

### 9.3 經典劇本判定

```javascript
triple = "曖昧型-熱戀型-失戀型"
if triple in CLASSIC_SCRIPTS:
    顯示劇本彩蛋卡
else if 三型相同:
    顯示「同型穩定劇本」彩蛋卡
else:
    不顯示彩蛋卡
```
